Optional media. Every page already has a live, code-drawn scene (src/scenes.js).
Files you add here are layered on top: a video or image covers the scene, music plays.

home/bg.mp4, home/bg.jpg, home/bgm.mp3          home page
anime/realm.mp4 or realm.jpg, realm.mp3          Anime event list page (video/image, music)
hoyoverse/realm.mp4 or realm.jpg, realm.mp3      HoYoverse event list page (video/image, music)

<realm>/<event-id>.mp4      live wallpaper for that event (muted loop)
<realm>/<event-id>.jpg      still background (used if no video)
<realm>/<event-id>.mp3      event music
<realm>/<event-id>-char.webp   character art beside the form (transparent PNG/WebP/GIF)

Event ids: voice-anime, voice-character, seiyuu, opening, scene, lore,
mondstadt, liyue, inazuma, sumeru, fontaine, star-rail.

Only use media you have the right to show and play. Character art and OSTs
belong to their studios, even when a site offers them for free.
