# AniMahou: Design Lock (v4, game-menu realms)

## Anchor
**A fantasy RPG start menu.** Dark navy night, gold-trimmed translucent panels, cream pill buttons with round icon badges, and each event page dressed in its own world's background and music.

## Structure (kiosk)
Home (Lottie emblem + two realms) → Realm (Anime or HoYoverse event list) → Event page (themed background + music + registration) → Quiz (3 questions) → Result (stars, saved) → Home after 12 s.
- Data: `public/data/realms.json`, `events.json` (each event has a `theme` with `name`, `bg`, `bgm`, `tint`), `questions.json` (keyed by `event`).
- Scores: `localStorage` key `animahou.plays` until the real DB.

## Media slots (bring your own, see `public/media/README.txt`)
| Slot | Path | Fallback |
|---|---|---|
| Home live wallpaper | `/media/home/bg.mp4` (muted loop) | painted tint gradient + ridges + glows |
| Home still | `/media/home/bg.jpg` | same |
| Home music | `/media/home/bgm.mp3` | silence |
| Event background | `/media/<realm>/<event-id>.jpg` | event `tint` gradient |
| Event music | `/media/<realm>/<event-id>.mp3` | silence |
Only use media you have the right to play and show. Missing files fail silently.

## Lottie
`public/lottie/emblem.json`, an original star-compass, generated by `scripts/make-emblem.py`. Any LottieFiles JSON saved under that name replaces it. The emblem tilts toward the pointer, speeds up on hover, and bursts on click. With reduced motion it is a still frame.

## Type
- **Display:** Cinzel 600/700, for titles, theme names, counters and scores. Large titles use the gold gradient.
- **UI:** Nunito 600/700/800.
- Scale: `--t-xs` .8125, `--t-sm` .9375, `--t-md` 1.0625, `--t-lg` 1.375rem, `--t-xl` clamp(1.75–2.6rem), `--t-2xl` clamp(2.4–4.5rem), `--t-hero` clamp(3–7.5rem).

## Spacing
4, 8, 12, 16, 24, 32, 48, 72 (`--s-1`…`--s-8`). Margin `clamp(16px, 4vw, 56px)`.

## Components
- **Button:** cream pill, 52px tall (40px small), with a dark 40px circular badge holding an icon on the left. Hover adds a white 3px halo. `btn-ghost` is a navy pill with a cream outline (back links).
- **HUD buttons:** 40px circles with a cream outline: leaderboard, music on/off, full screen. A clock and a "now playing" chip sit beside them.
- **Panel:** translucent navy, 1px gold line, inner double frame, gold diamond at top and bottom centre.
- **Realm card:** tinted banner with a large faint sigil that rotates on hover, the realm name in Cinzel, and an "Enter" pill.
- **Event card:** themed art (image or tint), dark bottom gradient, gold theme name, Cinzel title, a meta line with question count and joined count. Hover: gold inner border and the art zooms.
- **Answer option:** navy pill with a letter badge. Hover nudges it right. Correct turns cream; wrong turns muted red with a strikethrough.
- **Result:** 0–3 stars (66% / 33% / any points), score in Cinzel gold, auto-return countdown.

## Icons
An original set in `index.html` (`#i-star`, `#i-wish`, `#i-compass`, `#i-scroll`, `#i-gem`, `#i-trophy`, `#i-note`, …), drawn as game-menu glyphs. No copied game icons.

## Motion
- Home: title letters rise in with a blur (60ms stagger), realm cards follow. Light motes rise slowly on a canvas, and background glows drift (30–38 s).
- Page enter: 450ms fade plus a 10px rise. Hover: 180ms.
- `prefers-reduced-motion`: no animation, no video, static emblem.

# Admin design (v1)

## Anchor
**Apple-style system UI.** Light grey canvas, white rounded cards, a translucent sidebar, system font, and one blue accent. Neutral and calm, with no theming from the kiosk. Scene thumbnails are the only illustration.

## Tokens (`src/admin/admin.css`)
| Token | Value | Role |
|---|---|---|
| `--bg` | `#F5F5F7` | canvas |
| `--surface` | `#FFFFFF` | cards, sheets |
| `--fill` / `--fill-2` | `#E8E8ED` / `#F2F2F5` | secondary buttons, segmented control, hover |
| `--text` / `--text-2` / `--text-3` | `#1D1D1F` / `#6E6E73` / `#86868B` | text levels |
| `--sep` / `--sep-soft` | `#D2D2D7` / `#E5E5EA` | input borders, row separators |
| `--accent` | `#0071E3` | primary buttons, links, nav icons |
| `--green` / `--red` / `--orange` (+ `-soft`) | `#248A3D` / `#D70015` / `#B25000` | open/correct, delete/wrong, unfinished |
| Radius | 8 / 12 / 18px | inputs / rows / cards and sheets; buttons are pills |
| Font | `-apple-system`, SF Pro, Helvetica Neue | 14px body, 30px page titles, 17px section titles |

## Components
- **Sidebar:** brand, five pages (Overview, Events & questions, Registrations, Responses, Leaderboards), "Open kiosk" and "Sign out" at the bottom. On phones it becomes a top bar.
- **Sheet:** a centred modal for every create/edit form and for play details. Escape or a click outside closes it, and errors show in the footer.
- **Switch:** green when on (event open, reveal picture). **Segmented control:** question type, time range.
- **Badges:** Open (green), Closed (grey), Unfinished/Playing (orange), question type (blue).
- **Tables:** hairline rows, right-aligned tabular numbers, clickable rows open details.
- **Toasts:** dark pills at the bottom centre that confirm saves ("Question added").
- Overview and Leaderboards refresh every 15 seconds during the event.
